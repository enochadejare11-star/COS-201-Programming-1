## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables.
- Use appropriate primitive data types.
- Perform arithmetic calculations.
- Receive keyboard input using Scanner.
- Display formatted output.
- Compile and run Java programs.

### Programs
1. **SimpleCalculator.java**
   - Performs addition, subtraction, multiplication and division on two numbers.

2. **AverageCalculator.java**
   - Calculates the total and average of three scores.

3. **ItemCost.java**
   - Calculates the total cost of items using quantity and unit price.

### How to Run

Open the terminal inside the week03 folder.

To run SimpleCalculator:
- javac SimpleCalculator.java
- java SimpleCalculator

To run AverageCalculator:
- javac AverageCalculator.java
- java AverageCalculator

To run ItemCost:
- javac ItemCost.java
- java ItemCost
